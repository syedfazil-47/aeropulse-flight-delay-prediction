# ✈ AeroPulse — AI-Powered Flight Intelligence

**Midnight Aviation** is a premium dark-themed dashboard prototype for exploring departure and arrival delay risks on Indian domestic flight routes.

> **Current status: synthetic-data demonstration.** The models bundled here are trained on generated records, **not actual airline history**. Scores are illustrative, not verified probabilities or real-world accuracy. The app does not check actual flight timetables, live operations, or weather. Do not use its results to make travel decisions.

## Preview features
- Midnight navy, cyan, and amber Streamlit dashboard
- Flight-number, route, date, and scheduled-time inputs
- Separate departure and arrival delay classification demonstrations
- Support for sample airline prefixes: 6E, AI, QP, IX
- Sample airports: DEL, BOM, HYD, BLR, MAA, CCU, PNQ, GOI
- Validation checks and GitHub Actions CI

## Run locally or in a cloud development environment

```bash
pip install -r requirements.txt
python -m ml.train
streamlit run app/main.py
```

The demo model files are generated by the training command and are intentionally not included in the repository. If absent, the app generates the demonstration models on first prediction.

## Deploy to Streamlit Community Cloud (later)
1. Push this project to a public GitHub repository.
2. The app will train its synthetic demonstration models on first use if they are missing.
3. Set the entrypoint to `app/main.py`.
4. Replace synthetic models with validated models trained on appropriately licensed real flight data before describing the service as operational.

## Model definition
A delayed flight is defined as an arrival or departure **15 minutes or more** after schedule. This definition must be applied consistently when training on real records.

## Important limitations
A flight number alone is not sufficient to guarantee a matching scheduled flight. No actual API calls or automated updates are implemented yet. Free-tier API availability and carrier coverage must be verified separately. No production accuracy claim is made.
