# ✈️ AeroPulse — AI-Powered Flight Intelligence

**Predicting Indian domestic flight delays using Machine Learning and real-time aviation data.**

AeroPulse is a flight delay prediction system designed to estimate departure and arrival delay risks for Indian domestic flights.

The platform combines historical flight data, weather information and available aviation updates to generate intelligent predictions.

## 🎯 Project Objectives

- Predict flight departure delays.
- Predict flight arrival delays.
- Support multiple Indian domestic airlines.
- Integrate flight and weather information.
- Provide an interactive aviation analytics dashboard.
- Automate data collection and updates.

## 🧠 Machine Learning

AeroPulse will use two separate machine learning models:

1. Departure Delay Prediction
2. Arrival Delay Prediction

**Delay definition:** 15 minutes or more beyond the scheduled time.

## 🛠️ Technology Stack

- Python
- Pandas & NumPy

## 📊 Key Features

- Departure and arrival delay probabilities
- Historical flight analysis
